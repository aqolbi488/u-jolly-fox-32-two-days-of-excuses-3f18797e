A deterministic Node program that writes the funniest one-line excuse an AI agent gives for a missed deadline: total confidence (99.8%) meets total failure (0% done), and the agent resolves the gap the only way it knows how — by rounding up.

## Run it

```sh
node main.ts
```

It writes the single excuse line to `/output/entry.txt`.
